# Design System: CLOSERS

## Overview

**Creative North Star: "POIZON, но CLOSERS"**

Первая версия редизайна («Табло обменника») строила отдельный визуальный мир — split-flap табло, амбер+зелёный+красный, декоративные швы, перфорированная бумага, кастомный дисплейный шрифт. Пользователь отклонил её целиком: «не так цветасто, попроще, основные цвета как у POIZON». Проверено по официальной странице POIZON в App Store — их фирменный стиль почти монохромный: чёрная иконка, белый логотип-леттеринг, один бирюзовый акцент на букве «I». CLOSERS повторяет эту сдержанность буквально: чёрный фон, белый текст, ровно один акцент, никакой второй или третьей насыщенной краски.

Это Operate-поверхность (каталог → корзина → заказ), не витрина, поэтому решение здесь — не «придумать мир», а убрать всё, что отвлекает от задачи: системный шрифт вместо кастомного, обычные скруглённые карточки вместо декоративных швов, один слой материала (тёмная поверхность) вместо двух (тёмная панель + бумажный талон).

**Key Characteristics:**
- Один акцент (бирюза `#1fd8c1`), больше никаких вторых насыщенных цветов
- Системный шрифт везде, включая логотип — никакого кастомного дисплейного шрифта
- Обычные скруглённые поверхности (8-16px), без имитации механических швов/перфорации
- Один материал: тёмная приподнятая поверхность (`surface`/`surface-2`) — без переключения на «бумагу» в модалках
- Карточки товара готовы принять реальное фото (`<img>` с fallback на иконку категории)

## Colors

Restrained-стратегия: нейтральная тёмная база, один акцент, минимум насыщенного цвета на экране.

### Primary
- **Бирюза POIZON / Accent** (`#1fd8c1`): единственный акцент во всей системе — первичные кнопки, активная категория/вкладка, цена товара «в фокусе», статус «выполнено/в процессе», акцентная буква «O» в логотипе.

### Neutral
- **Фон / BG** (`#0a0a0a`): базовый фон страницы.
- **Поверхность / Surface** (`#161616`) и **Surface 2** (`#1e1e1e`): приподнятые панели — карточки, шапка баннеров, вложенные блоки.
- **Граница / Border** (`#292929`): разделители, обводка полей ввода.
- **Текст** (`#ffffff` / `#9a9a9a` / `#6b6b6b`): первичный / вторичный / третичный текст.

### Tertiary
- **Тревога** (`#ff5449`): только текст ошибки (неверный промокод, сбой сети).
- **Scrim** (`rgba(0,0,0,.7)` / `rgba(0,0,0,.75)`): затемняющая подложка модалок и мелкой кнопки удаления фото — нейтральный чёрный, не считается вторым акцентом.

### Named Rules
**The One Accent Rule.** На экране ровно один насыщенный цвет — бирюза. Любой второй цвет (кроме нейтральных чёрно-белых оттенков и красного текста ошибки) — драйф от системы, а не осознанное решение.

## Typography

**Body/Display Font:** системный стек (`-apple-system, Segoe UI, Roboto, Helvetica, Arial`) — единственная гарнитура во всей системе, включая логотип.

**Character:** нейтральный рабочий гротеск; иерархия держится на весе/размере, не на смене шрифта.

### Hierarchy
- **Display** (800, 30px): логотип CLOSERS в шапке, заголовок «Поддержка».
- **Title** (700-800, 13.5-16px): названия товаров, ID заказа, заголовки модалок.
- **Body** (400-600, 12-14px): описания, текст FAQ, подписи форм.
- **Label** (600-800, 9.5-12px, часто uppercase): категории, бейджи, статусы.

## Layout

Контейнер `max-width: 600px`, одна колонка. Каталог — сетка 3 колонки, 10px зазор между карточками (обычный `gap`, не декоративный шов фона). Компактная плотность: внутренние отступы 8-16px.

## Elevation & Depth

Плоская тональная система: глубина передаётся разницей фона (`bg` → `surface` → `surface-2`), теней почти нет (только у плавающей кнопки запроса — мягкая цветная тень под акцентным цветом, `0 6px 16px rgba(31,216,193,.25)`).

### Named Rules
**The Flat-By-Default Rule.** Поверхности плоские в состоянии покоя. Тень — исключение для одного плавающего элемента, не системный приём.

## Shapes

Обычные скруглённые прямоугольники (8-16px радиус) и полное скругление (`full`, 999px) для пилюль/бейджей/круглых счётчиков. Никакой имитации механических материалов (швы, перфорация, «рейки»).

## Components

### Buttons
- **Shape:** `--radius-md` (12px) для основной кнопки, `--radius-full` для пилюль (категории, бейдж админ-чата, промо-кнопка).
- **Primary:** фон `accent`, текст `accent-ink`, заполняет ширину контейнера.
- **Active:** `opacity: 0.85` — простой прижим, без анимаций.
- **Secondary:** фон `surface-2`, текст `text`, без акцента.

### Cards / Containers
- **Corner Style:** `--radius-lg` (16px) для карточек верхнего уровня (корзина, заказ, поддержка), `--radius-md`/`sm` для вложенных блоков.
- **Background:** `surface` на `bg`, без границ (граница только у полей ввода и промокода).

### Inputs / Fields
- Фон `bg`, граница `border` (1px), фокус — граница `accent`. Один материал везде, включая модалки.

### Navigation
Нижняя панель — сплошная плашка `surface` с верхней границей `border`; активный пункт — просто акцентный цвет иконки/текста, без заливки/пилюли.

### Product Card (сигнатурный компонент)
`.product-image` — единственное место в системе с белым фоном (`#ffffff`) — сознательный контраст с тёмным приложением: фото товара должно выглядеть как обычная каталожная студийная съёмка, а не тонироваться под тёмную тему. `object-fit: contain` (не `cover`) — товар виден целиком, не обрезается. Фолбэк при отсутствии/ошибке фото — светло-серый (`#f4f4f4`) с иконкой категории (`#c4c4c4`), не тёмная поверхность. Модалка товара повторяет тот же приём: `.modal-gallery` — белая горизонтальная свайп-галерея (`scroll-snap-type: x mandatory`) с точками-индикаторами, вставленная встык в верх тёмной модалки. Карточка также несёт `.wishlist-btn` — полупрозрачный чёрный кружок в левом верхнем углу превью, зеркальный по расположению `.cart-badge-mini` в правом верхнем.

### Search & Filter Toolbar
Строка над категориями: `.search-input-wrap` (тёмное поле поиска, `surface`, без явной границы, только фокус через нативный курсор) + `.wishlist-toggle` — квадратная pill-кнопка того же роста, что и поле поиска, переключается в акцентный `accent`/`accent-ink` при активном фильтре «только избранное» — та же логика состояния active, что у `.category-tab.active`.

### Size Guide
`.size-table` — обычная HTML-таблица на `surface-2` шапке и `border`-разделителях между строк, без декоративных цветовых акцентов на данных. Открывается тем же bottom-sheet `.modal`, что и остальные модалки — не отдельный визуальный язык.

## Do's and Don'ts

### Do:
- **Do** держать ровно один акцентный цвет на экране (`#1fd8c1`).
- **Do** использовать системный шрифт везде — не подключать кастомные/CDN-шрифты.
- **Do** давать `.product-image` реальное фото с fallback на иконку, а не наоборот.

### Don't:
- **Don't** добавлять второй насыщенный акцент (никакого зелёного/жёлтого/фиолетового рядом с бирюзой).
- **Don't** имитировать физические материалы (перфорация, швы-рейки, тиснение) — это был отклонённый пользователем мир.
- **Don't** добавлять цветной `border-left`/`border-right` на карточки.
